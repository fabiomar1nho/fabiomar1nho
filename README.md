## 📌 Projetos

Aqui você encontra ferramentas e experimentos desenvolvidos ao longo da minha jornada, com foco em **produtividade, automação e processamento local**:

### 🌐 Aplicações Web

* **[MarPDF](https://fabiomar1nho.github.io/MarPDF/)** — [Código-fonte](https://github.com/fabiomar1nho/MarPDF)  
  Suíte web completa, gratuita e sem necessidade de login para manipulação de documentos. Permite juntar, dividir, editar, converter e comprimir PDFs, digitalizar via câmera e preparar arquivos para impressão diretamente no navegador.  
  `HTML5` `JavaScript` `PDF-Lib` `PDF.js`

* **[Extrator de Coordenadas UTM](https://fabiomar1nho.github.io/Extrator-de-Coordenadas-UTM/)** — [Código-fonte](https://github.com/fabiomar1nho/Extrator-de-Coordenadas-UTM)  
  Ferramenta voltada para agrimensores, engenheiros e analistas ambientais. Automatiza a leitura de coordenadas UTM em textos brutos e memoriais descritivos, convertendo os dados para formatos georreferenciados (`.KML` e `.CSV`) prontos para Google Earth e softwares GIS.  
  `HTML5` `JavaScript` `Geoprocessamento`

### 🧩 Extensões de Navegador

* **[Área de Transferência Lateral](https://github.com/fabiomar1nho/Area-de-transferencia-lateral)** — [Código-fonte](https://github.com/fabiomar1nho/Area-de-transferencia-lateral)  
  Extensão para Google Chrome (Manifest V3) que captura, salva e organiza textos copiados em tempo real no painel lateral do navegador. Conta com adição de notas, formatação rápida, controle liga/desliga e exportação em `.TXT` com armazenamento 100% local.  
  `Chrome Extension` `Manifest V3` `JavaScript`
